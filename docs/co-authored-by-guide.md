# Co-authored-by Guide

## What is Co-authored-by?
When multiple developers work on a PR, all contributors must receive credit.

## How to Add Co-authored-by
In your commit message add:

Co-authored-by: FirstName LastName <email@example.com>

## Example
Add login feature (#12)

Co-authored-by: Gautham <gautham@example.com>

## Rules
- Add one Co-authored-by line per contributor
- Use their GitHub registered email
- Add after a blank line below commit message
